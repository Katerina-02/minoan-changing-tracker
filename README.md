# Αλλαγές παροχών — Μινώα Ενεργειακή

Εφαρμογή καταγραφής αιτημάτων αλλαγών παροχών, με πραγματικούς λογαριασμούς
χρηστών και βάση δεδομένων Postgres — ώστε να τη χρησιμοποιούν πολλά άτομα
ταυτόχρονα από διαφορετικούς υπολογιστές χωρίς να χάνονται δεδομένα.

Χτισμένη με Next.js + Prisma. Η ίδια η εφαρμογή (η οθόνη καταχώρησης/προβολής/
αναζήτησης/στατιστικών) είναι το αρχικό αρχείο σε καθαρή HTML/JS
(`src/app/tracker/content.html`) — δεν άλλαξε η εμφάνιση ή η λειτουργία της,
άλλαξε μόνο το πού αποθηκεύονται τα δεδομένα.

## Τι άλλαξε σε σχέση με την παλιά έκδοση (Claude artifact)

- Τα δεδομένα δεν αποθηκεύονται πια μέσα στο Claude — αποθηκεύονται σε δική
  σας βάση δεδομένων Postgres (Neon), που δεν εξαρτάται από το Claude.
- Αντί για έναν κοινό κωδικό πρόσβασης, κάθε άτομο έχει δικό του λογαριασμό
  (email + κωδικός).
- Κάθε αλλαγή αποθηκεύεται αμέσως ξεχωριστά στη βάση (όχι "όλα μαζί σε ένα
  μπλοκ"), οπότε αν δύο άτομα καταχωρήσουν κάτι ταυτόχρονα δεν διαγράφει το
  ένα το άλλο. Κάθε ~20 δευτερόλεπτα η σελίδα ελέγχει αθόρυβα για αλλαγές
  που έκαναν άλλοι, ώστε η οθόνη σας να μένει ενημερωμένη.

## Μεταφορά των υπαρχόντων δεδομένων

Πριν αρχίσετε να χρησιμοποιείτε τη νέα σελίδα, βγάλτε αντίγραφο των
υπαρχόντων δεδομένων από την παλιά (μέσα στο Claude), με τα κουμπιά "⬇ Excel"
που υπάρχουν ήδη σε κάθε έργο. Μετά, στη νέα σελίδα, πηγαίνετε στην
"Καταχώρηση" → "⇅ Μαζική εισαγωγή από Excel" και ανεβάστε τα αρχεία — θα
χρειαστεί να τα μορφοποιήσετε λίγο ώστε να ταιριάζουν με το πρότυπο εισαγωγής
(κουμπί "⬇ Λήψη προτύπου Excel").

## Τοπική εκτέλεση / πρώτη εγκατάσταση

1. **Neon Postgres (δωρεάν, ξεχωριστό από κάθε άλλη εφαρμογή σας)**:
   Δημιουργήστε λογαριασμό στο [neon.tech](https://neon.tech), φτιάξτε ένα
   **νέο** project (π.χ. με όνομα "minoa-tracker" — μην χρησιμοποιήσετε τη
   βάση κάποιας άλλης σελίδας), και αντιγράψτε το connection string.

2. Βάλτε το connection string στο `.env`, στη μεταβλητή `DATABASE_URL`.
   Το `SESSION_SECRET` έχει ήδη γεμίσει με ένα τυχαίο string· αν θέλετε να
   βάλετε δικό σας, μπορεί να παραχθεί με `openssl rand -hex 32`.

3. Εγκατάσταση εξαρτήσεων και δημιουργία των πινάκων στη βάση:
   ```bash
   npm install
   npx prisma migrate dev --name init
   ```

4. Ανοίξτε το `prisma/seed.ts` και αντικαταστήστε τη λίστα `USERS` με τα
   πραγματικά email/ονόματα των 5-10 ατόμων, βάζοντας για τον καθένα έναν
   προσωρινό κωδικό. Μετά τρέξτε:
   ```bash
   npx prisma db seed
   ```
   Αυτό είναι ασφαλές να το ξανατρέξετε αργότερα (π.χ. για να προσθέσετε
   άτομο ή να αλλάξετε κωδικό) — δεν δημιουργεί διπλότυπους λογαριασμούς,
   ενημερώνει με βάση το email.

5. ```bash
   npm run dev
   ```
   Ανοίξτε [http://localhost:3000](http://localhost:3000) — θα σας ζητήσει
   σύνδεση, και μετά θα δείτε την εφαρμογή.

**Σημείωση για κωδικούς**: κάθε συνδεδεμένος χρήστης μπορεί να αλλάξει μόνος
του τον κωδικό του από το μενού "Αλλαγή κωδικού" μέσα στην εφαρμογή (χρειάζεται
να ξέρει τον τρέχοντα). Αν κάποιος ξεχάσει εντελώς τον κωδικό του (δεν υπάρχει
"ξέχασα τον κωδικό μου"), ενημερώστε τη γραμμή του στο `prisma/seed.ts` με νέο
προσωρινό κωδικό και ξανατρέξτε `npx prisma db seed`.

## Deploy (δωρεάν) στο Vercel

1. **GitHub**: Δημιουργήστε ένα repository και ανεβάστε τον κώδικα
   (`git init`, `git add`, `git commit`, `git push`).

2. **Vercel**: Δημιουργήστε δωρεάν λογαριασμό στο
   [vercel.com](https://vercel.com) και κάντε "Import" το repository. Στις
   ρυθμίσεις του project προσθέστε τα environment variables:
   - `DATABASE_URL` — το ίδιο connection string από το Neon
   - `SESSION_SECRET` — το ίδιο (ή νέο) τυχαίο string

3. Μετά το πρώτο deploy, τρέξτε τοπικά (με το production `DATABASE_URL` στο
   `.env`) — αυτό δημιουργεί τους πίνακες στην production βάση:
   ```bash
   npx prisma migrate deploy
   npx prisma db seed
   ```

4. Το Vercel θα σας δώσει ένα link τύπου `https://το-ονομα.vercel.app` — αυτό
   είναι το link που μοιράζεστε με τα 5-10 άτομα. Ανοίγοντάς το θα τους
   ζητήσει email + κωδικό.

## Δομή

- `src/app/tracker/content.html` — η ίδια η εφαρμογή (HTML/CSS/JS), σχεδόν
  αναλλοίωτη από την αρχική έκδοση· μιλάει με τα `/api/entries` και
  `/api/contacts` αντί για το `window.storage` του Claude.
- `src/app/tracker/route.ts` — σερβίρει το παραπάνω αρχείο, γεμίζοντας το
  όνομα/email του συνδεδεμένου χρήστη.
- `src/app/api/entries`, `src/app/api/contacts` — τα endpoints της βάσης
  (μία εγγραφή τη φορά, όχι "όλα μαζί").
- `src/app/login`, `src/app/api/login`, `src/app/api/logout` — σύνδεση/
  αποσύνδεση.
- `src/middleware.ts` — μπλοκάρει την πρόσβαση σε `/tracker` και `/api/*`
  χωρίς έγκυρη σύνδεση.
- `prisma/schema.prisma` — μοντέλο βάσης δεδομένων (`User`, `Entry`,
  `Contact`).
- `prisma/seed.ts` — εδώ προσθέτετε/αφαιρείτε λογαριασμούς χρηστών.
